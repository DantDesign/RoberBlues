# Roberto | Chicago Blues 🎸✨

¡Bienvenido al repositorio oficial de la plataforma web de **Roberto**, músico solista independiente dedicado al Chicago Blues! Este sitio web está diseñado para conectar al artista con su público, difundir su música, promocionar sus libros autoeditados y gestionar su agenda de conciertos en vivo.

🔗 **Sitio en producción:** [robertoblues.vercel.app](https://robertoblues.vercel.app/)

---

## 📖 Características del Sitio

El sitio cuenta con una arquitectura de sección única (Single Page) optimizada para la navegación rápida (Scroll) y una estética oscura clásica del género Blues.

- **01 Historia:** Introducción al perfil artístico de Roberto Porzio.
- **02 Música (Listen):** Reproductor de Spotify con una selección de temas originales y covers (ej. *Forty Days & Forty Nights*, *Walk On*).
- **03 Libros:** Catálogo y tienda de ediciones independientes escritas por el artista (precios integrados en ARS).
- **04 Fechas (Live):** Agenda actualizada de shows en vivo con locaciones, horarios y accesos a información de reservas.
- **05 Galería (Moments):** Registro visual interactivo de presentaciones en vivo.
- **06 Contacto:** Canales directos integrados (Email, Instagram, YouTube y WhatsApp) para contrataciones y prensa.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando herramientas modernas de desarrollo web para garantizar velocidad, SEO y adaptabilidad móvil:

- **Frontend:** HTML5/CSS3/JS
- **Estilos:** Tailwind CSS / CSS Modules (Diseño responsivo y amigable con dispositivos móviles).
- **Despliegue y Hosting:** [Vercel](https://vercel.com) (CI/CD automático acoplado a la rama principal).
